# Formación por cargo

La formación oficial de IEEE para voluntarios está en el **Center for Leadership Excellence (CLE)**. Inicia sesión con tu cuenta IEEE y entra a **Volunteers**. Allí encuentras tres cosas para cada cargo:

- **Descripción del cargo** (*Role Description*): qué se espera de ti.
- **Plan de acción** (*Action Plan*): listas de tareas para los primeros 30 días, tareas administrativas clave y tareas anuales, con los recursos para cada una.
- **Cursos recomendados** (*Recommended Training*): cursos en línea para tu rol.

- [CLE · Volunteers](https://ieee-elearning.org/totara/dashboard/index.php?id=2): Punto de entrada. Requiere cuenta IEEE.
- [Descripciones de cargos (Role Descriptions)](https://ieee-elearning.org/mod/page/view.php?id=1998)
- [Planes de acción (Action Plans)](https://ieee-elearning.org/course/view.php?id=267)
