# Herramientas digitales

Plataformas oficiales de IEEE para reportar, comunicar y gestionar miembros.

<div class="grid cards" markdown>

-   **[vTools](https://vtools.ieee.org/)**

    Suite de herramientas para voluntarios: Officer Reporting (junta), Events (eventos), SB Reporting (Plan Anual), eNotice y más.

-   **[OU Analytics](https://mga.ieee.org/volunteer-hub/volunteer-tools/ou-analytics)**

    Lista de miembros, estadísticas y renovaciones pendientes de tu unidad. Reemplazó a SAMIEEE.

-   **[eNotice](https://enotice.vtools.ieee.org/)**

    Envía convocatorias por correo a los miembros de tu unidad.

-   **[IEEE Collabratec](https://ieee-collabratec.ieee.org/app/home)**

    Red profesional de IEEE con comunidades y espacios de trabajo.

-   **[Hosting web de IEEE](https://site.ieee.org/)**

    Alojamiento gratuito para el sitio web de la Rama.

-   **[Base de conocimiento de vTools](https://kb.ieee.org/vtools/blog/kbtopic/vtools/)**

    Tutoriales y respuestas a preguntas frecuentes.

</div>
